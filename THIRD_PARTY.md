# Third-party components

## Wheeltec / Roboworks Gazebo model

The Wheeltec / Roboworks simulation model in

`wheeltec_autorace_description/models/roboworks/`

is derived from:

robotverseny/robotverseny_gazebo24

Source:
https://github.com/robotverseny/robotverseny_gazebo24

Imported revision:

`b7fd10b8d75e16c72dd170d7f3859483961422f6`

The upstream project is distributed under the Apache License 2.0.

Local modifications:

- ROS package references were renamed from
  `robotverseny_description`
  to
  `wheeltec_autorace_description`.
- The model is embedded into the
  Wheeltec AutoRace simulation project.
